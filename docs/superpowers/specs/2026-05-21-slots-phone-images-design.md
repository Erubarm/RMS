# Дизайн: тестовые слоты, телефон в бронировании, картинки в афише

**Дата:** 2026-05-21  
**Проект:** VK Mini App «Россия — Моя история»

---

## 1. Тестовые временные слоты

### Цель
Обеспечить стабильные демо-данные для показа работы системы бронирования независимо от даты запуска сида.

### Решение
В `server/prisma/seed.js` заменить динамическую генерацию слотов (14 дней от текущей даты) на жёстко заданный диапазон дат: 22 мая — 30 июня 2026 года.

### Детали
- Времена: `11:00`, `13:00`, `15:00`, `17:00`
- Дни работы: среда–воскресенье (понедельник и вторник пропускаются)
- Экскурсии: все 6 (без изменений)
- Итого: ~160 слотов
- Логика очистки (`deleteMany`) не изменяется

## 2. Номер телефона в форме бронирования

### Цель
Привязать контактный телефон к каждой записи, чтобы администратор мог связаться с посетителем.

### Схема БД
Добавить поле в модель `Booking` в `schema.prisma`:
```prisma
phone String
```
Применить изменение через `prisma db push`.

### Бэкенд
- Контроллер `POST /api/bookings` принимает поле `phone` из тела запроса
- `phone` — обязательное строковое поле
- Сохраняется в запись `Booking`

### Фронтенд (`client/src/pages/Booking.jsx`)
Форма расширяется с 4 до 5 шагов:

| Шаг | Содержание |
|-----|-----------|
| 1/5 | Выбор экскурсии |
| 2/5 | Выбор даты |
| 3/5 | Выбор времени и количества |
| 4/5 | Ввод телефона (новый шаг) |
| 5/5 | Подтверждение + отправка |

**Новый шаг 4:**
- `FormItem top="Номер телефона"`
- `Input type="tel"` 
- Базовая валидация: не пустое, содержит цифры
- Кнопка «Далее»

**Шаг 5 (бывший шаг 4):**
- Добавить строку `<b>Телефон:</b> {phone}` в сводку данных
- Передать `phone` в тело запроса `POST /api/bookings`

## 3. Картинки в афише и событиях

### Цель
Визуально обогатить карточки экспозиций и событий тематическими историческими изображениями.

### Seed — экспозиции
Добавить `imageUrl` в каждую из 4 экспозиций. Источник: Wikimedia Commons (публичное достояние).

| Экспозиция | Изображение |
|-----------|-------------|
| Рюриковичи | Миниатюра «Призвание варягов» |
| Романовы | Портрет Петра I (Готфрид Кнеллер) |
| От великих потрясений к Великой Победе | Фото советских солдат, 1945 |
| Россия — Моя история (1945 — наши дни) | Запуск Спутника-1, 1957 |

### Seed — события
Добавить `imageUrl` к каждому из 5 событий — тематические публичные изображения.

### `Poster.jsx`
Изменений не требуется — компонент уже корректно отображает `imageUrl` с fallback-градиентом.

### `Events.jsx`
Добавить блок изображения в карточку события перед текстом:
- Высота: 140px
- `objectFit: cover`, `borderRadius: '8px 8px 0 0'`
- Fallback: градиент `linear-gradient(135deg, #667eea 0%, #764ba2 100%)` с иконкой
- Аналогично реализации в `Poster.jsx`
